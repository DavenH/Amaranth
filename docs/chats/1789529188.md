# Experimental Pitch-Independent Spectral Control

Date: 2026-09-16

## Context

Whole-cycle spectral scheduling concealed fast authored timbre changes on low
notes. The first product trial needed a representative evolving preset without
changing legacy preset playback globally.

## Decisions

- Gate pitch-independent spectral control in Voice Context configuration and
  keep it disabled by default.
- Use a copied Acoustic preset with a 64-sample interval for the first audible
  experiment; preserve the original preset unchanged.
- Keep the clock, periodic lookup, and complementary blend in shared Cycle DSP
  code while reusing the existing V2 spectral-frame renderer unchanged.
- Treat live CPU measurements as evidence for the experimental setting, not as
  a shipping-default decision.

## Generalized Rules

- Introduce costly synthesis-cadence experiments through explicit per-voice
  configuration so legacy content remains comparable.
- Pair a new synthesis mode with a deliberately revealing preset copy and
  retain the source preset as its listening reference.
- Prove low-note within-cycle change, block independence, event causality,
  Unison sharing, and realtime safety before judging the sound.

## Open Questions

- Complete Cycle 1 integration before promoting the mode beyond the V2
  experiment.
- Measure the full interval, pitch, polyphony, and Unison matrix before choosing
  a default quality policy.
