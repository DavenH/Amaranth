# Envelope 3D playback and colour semantics

Date: 2026-10-27

## Context

Full-height time cursors were confused with the transposed morph slice lines.
Most pitch-envelope values sit close to 0.5; extending sampler padding looked
like an authored release region.

## Decisions

- In Envelope 3D, show each voice's primary morph cut line with a dot moving
  along Phase/time. Keep actual scratch, loop and ADSR positions from audio.
  This supersedes the full-panel Phase sweep in the original cursor design.
- Use flat Blues for unipolar envelopes, with yellow loop and red release hues.
  Pitch keeps a bipolar map so small signed deviations remain distinguishable.
- Beyond each morph slice's authored endpoint, show background. Sampler padding
  and an absent release must never manufacture a red release region.

## Generalized Rules

Choose envelope colour encodings by signal meaning; preserve pitch's centre
and sign. Derive visible section coverage from authored envelope geometry and
mature marker/playback policies, independently of extrapolated sample values.
