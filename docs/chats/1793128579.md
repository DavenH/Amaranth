# Envelope 3D playback and colour semantics

Date: 2026-10-27

## Context

Full-height time cursors were confused with the transposed morph slice lines.
Most pitch-envelope values sit close to 0.5; extending sampler padding looked
like an authored release region.

## Decisions

- In Envelope 3D, show each voice's primary morph cut line with a hollow diamond
  moving along Phase/time. Keep actual scratch, loop and ADSR positions from audio.
  Diamonds distinguish playback from editable circular intercepts. This
  supersedes the full-panel Phase sweep and subsequent circular playback dots.
- In Trimesh, show stationary diamonds above the primary-axis strip when the
  viewed axis is active and linked to keyboard mapping. Use the configured axis,
  not a hardcoded Red. Place each at its actual voice key coordinate and retire
  it on voice end, including release. Sampled waveform/frequency is not time.
- Use flat Blues for unipolar envelopes; share 2D section hues for blue, amber
  loop and maroon release while retaining 3D's amplitude/brightness ramp.
  Pitch keeps a bipolar map so small signed deviations remain distinguishable.
- Beyond each morph slice's authored endpoint, show background. Sampler padding
  and an absent release must never manufacture a red release region.

## Generalized Rules

Choose envelope colour encodings by signal meaning; preserve pitch's centre
and sign. Derive visible section coverage from authored envelope geometry and
mature marker/playback policies, independently of extrapolated sample values.
