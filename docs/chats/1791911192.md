# Voice Context pitch and hover cues

Date: 2026-10-13

## Context

The compact Voice Context's struck-through ottava symbol and duplicated port
tooltip obscured the pitch state and quick-create action.

## Decisions

- This supersedes the previous preference for struck-through ottava notation
  in the collapsed Voice Context.
- Show octave shift as a signed number of semitones, including zero.
- Use a monochrome tuning fork for that value and space it clearly from the
  pitch input's tuning fork.
- Keep hover help in the canvas console line without a separate popup.
- Keep empty-port quick-create badges steady, with no hover-driven flicker.

## Generalized Rules

Make compact musical state legible at normal zoom. Separate repeated symbols
by enough space to distinguish property readouts from port functions. Avoid
duplicate hover explanations and hover-dependent authoring affordances.
