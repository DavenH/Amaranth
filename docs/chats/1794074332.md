# Remove redundant editor chrome before adding polish

Date: 2026-11-07

## Context

A MIDI editor proposal replaced a dense shortcut footer with a compact selection
readout and hint, and retained a title, transport button and stepper decoration.
The user still found those elements wasteful.

## Decisions

Visible metadata remains noise when its value is obvious or not needed for the
current action. Do not preserve an unnecessary bar by making its labels shorter.
Remove the bar and reclaim the space. Avoid adding a redundant editor title or
transport action when the enclosing interface already supplies that context.

## Generalized Rules

Treat vertical content area as a first-order constraint in editor proposals.
Reduce repeated lane padding before adding secondary labels or framed controls.
Keep useful precision cues such as ruler ticks; remove decorative or redundant
chrome. Apply these existing UI-skill rules in the first proposal rather than
waiting for the user to repeat them.
