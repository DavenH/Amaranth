# Causal Preview Gesture Semantics

Date: 2026-09-18

## Context

Cycle V2 Live mod-wheel and On Release Reverb gestures had ambiguous
transient-state and local-render semantics during the causal update migration.

## Decisions

- Live mod-wheel movement updates saved Trimesh and Envelope morph fields
  transiently, with one durable commit and undo at release.
- On Release Reverb movement keeps an accurate local spectrogram, including
  size and damping changes that require a new kernel.
- Kernel generation for that spectrogram is local render work. Graph
  compilation, downstream DSP preparation, traversal, and probes wait until
  release.

## Generalized Rules

- Make the current transient edit visible to preview workers through an
  immutable affected-state input, without copying the graph on movement.
- Judge local preview work by its product and dependency scope; expensive
  domain work can be justified when it is required for accurate immediate
  feedback and does not prepare unrelated downstream products.
