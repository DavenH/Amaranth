# Date

2026-07-31

# Context

Reviewing imported Cycle 1 presets exposed a distinction between immutable node
type metadata and preset-owned instance state.

# Decisions

- A node's displayed name belongs exclusively to its node definition.
- Presets must not serialize node names, even when the serialized value matches
  the definition.
- Node names are immutable for a given node type; semantic roles such as volume,
  pitch, layer number, or operation purpose must not masquerade as type names.

# Generalized Rules

- Persist only instance state. Resolve immutable type names from the definition
  registry at every presentation boundary.
- Treat redundant serialization of definition metadata as a second authority,
  not harmless descriptive data.
- Model semantic variants with typed parameters or graph grammar rather than
  mutable display names.
