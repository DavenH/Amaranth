# Cycle 2 keyboard shortcut direction

Date: 2026-10-18

## Context

Cycle 1 shortcuts were reviewed while adding contextual morph controls and a
focused-control keyboard glyph to Cycle 2.

## Decisions

- Model the focus glyph after a compact physical keyboard: rounded outer shell,
  two rows of round keys, and a centered spacebar.
- Keep `A` as the useful selection shortcut direction, covering select-all and
  clear-selection behavior once its Cycle 2 context is designed.
- Do not carry forward the `7`/`8`/`9` link aliases.
- Do not add `E` for extrude until Cycle 2 has a mature extrusion workflow.
- Leave `W` and `[`/`]` unassigned until their dependent workflows exist.

## Generalized Rules

Port shortcuts only when the operation behind them is mature and useful in the
current product. Prefer one memorable semantic key over legacy aliases, and
defer shortcuts whose visible workflow has not yet been designed.

## Open Questions

- Define whether `A` toggles all/none within the active editor, the canvas, or
  both before implementing it.
