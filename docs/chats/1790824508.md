# Preset-specific MIDI demonstrations

Date: 2026-10-01

## Context

Cycle 2 presets need an audible demonstration that reveals each sound's strength.

## Decisions

- Save the preview MIDI phrase with each preset and make it playable, recordable,
  and editable in a small piano roll.
- Shape phrases to the instrument: ambient pads use long, ethereal notes; basses
  use basslines; leads use melodies. MIDI CC or modulation movement should reveal
  useful variation where the preset responds to it.
- Centre the phrase's pitch range on the performance keyboard as well as its
  available two-octave view allows.

## Generalized rules

Treat preset presentation as part of the authored sound. Use musically specific
auditions rather than one generic fast note pattern for every preset.
