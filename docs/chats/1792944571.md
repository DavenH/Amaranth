# Deferred Spy release auditions

Date: 2026-10-25

## Context

A full voice/release Spy preview is useful for sustained notes but needs a quick
way to inspect staccato release from earlier positions.

## Decisions

- Drag the expanded Spy release marker to a normalized voice position x≤1.
- Pointer movement shows the marker only; update the Spy render on pointer-up.
- Keep the setting ephemeral and avoid immediate graph/document updates.

## Generalized Rules

For an inspection gesture, distinguish cheap local feedback from expensive
capture. Reuse actual envelope note-off playback rather than clipping the
existing image or simulating a separate UI envelope. Preserve a stable time
axis so early-release comparisons remain easy to read.
