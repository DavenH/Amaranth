# Shared Curve Interaction and Envelope Topology

Date: 2026-09-17

## Context

Shift-box selection reached Trimesh but not Guide or Envelope. Envelope also
exposed eight Time-pole storage vertices for a four-corner logical selection.

## Decisions

- Prefer one shared interaction algorithm/policy for Trimesh, Guide, and
  Envelope, with node-specific behavior only at narrow boundaries.
- Keep Envelope editing UI free of storage-only Time-pole markers and counts.
- A real two-axis Envelope mesh remains a separate model migration; do not
  mistake presentation cleanup for completed topology work.
- Boolean editor-mode toggles should feel immediate and must not copy or
  rerasterize a complete mesh just to flip the mode.
- Envelope links are session-only, always start on, ignore legacy saved states,
  and must not be serialized to presets.

## Generalized Rules

- When adding an editor gesture, audit sibling editors that use the same
  interaction base before declaring the feature complete.
- Treat unexpectedly heavy scalar changes as a boundary/ownership defect, not
  merely a repaint problem.
- Preserve recent edits in checked-in Cycle V2 presets: verify named Cycle 1
  parity gaps and patch only the specific affected preset data, never rerun a
  blanket migration over the preset library.
