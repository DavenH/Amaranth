# Envelope Import And Global Routing Cleanup

Date: 2026-09-12

## Context

Icycle exposed a synthetic Constant Modulation node connected twice to every
Envelope and a compact global effect lane whose persisted port-side overrides
still drew long arcing cables.

## Decisions

- Cycle 1 Envelope `dynamic=false` concerns its time/yellow dimension, not its
  red/blue modulation inputs.
- Cycle V2 Envelope has no grammatical time/yellow port and fixes that
  coordinate to zero during rendering, so conversion needs no graph node or
  cable for this behavior.
- Envelope red/blue inputs continue to consume the normal modulation triple.
- A migration that repacks a linear chain should also restore its audio ports
  to definition-owned sides; otherwise the visual routing remains unmigrated.

## Generalized Rules

- Do not materialize an inapplicable modulation dimension as compatibility
  topology. Enforce it at the domain renderer that owns the dimension.
- Treat persisted port-side overrides as part of layout migration, not as
  unrelated semantic state, when topology is a simple linear chain.

## Open Questions

- Repeat affected Cycle 1/V2 audio comparisons because prior Icycle and Guitar
  3 G parity evidence used the incorrect constant red/blue routing.

## Correction

The requested rerun disproved the red/blue audio conclusion above. Cycle 1
routes values into smoothed targets, but its voice-side smoothing update is
empty; the current values used by `EnvRasterizer` remain at initialized zero.
Removing the constant source changed Guitar 3 G from zero-lag `1.00000`
correlation to a `-451`-sample lag and `0.30556` correlation. Factory presets
therefore retain one explicitly named `legacyEnvelopeMorph` zero source, while
new V2 Envelope nodes continue to use normal Voice Context modulation.

## Update (2026-09-13)

Factory presets must no longer materialize Cycle 1's
constant-zero Envelope morph compatibility source. Remove `legacyEnvelopeMorph`
and its incident red/blue Envelope routes, use the normal implicit Voice Context
modulation behavior, and ensure conversion/migration tooling cannot recreate the
legacy node. This product direction supersedes the earlier audio-parity exception.
