# Date

2026-08-22

# Context

Native validation of the Cycle V2 Guide/Spy dock exposed misleading software
approximations and weak placeholder copy during UI iteration.

# Decisions

- Preserve the mature native OpenGL preview when relocating an existing visual;
  a simplified software recreation is a regression, not a fallback.
- Launch and capture Cycle through the repository automation scripts so native
  rendering and the actual application lifecycle are exercised.
- Do not put usage instructions in static empty-state labels. Vacancy copy
  should state what is absent and let nearby affordances explain available
  actions.
- Do not use generated Guide labels such as `G1` as shelf-card titles. Show a
  heading only when the user has supplied a meaningful name; retain stable
  labels where identity is needed in menus and assignment badges.

# Generalized Rules

- Trace and reuse an authoritative rendering path before implementing a preview
  of an existing editor.
- Treat native screenshots as required evidence for OpenGL UI changes.
- Prefer concise state labels and discoverable controls over permanent
  instructional prose in workspace chrome.

# Open Questions

- Continue refining the shared Guide/Spy dock layout through native captures as
  the remaining TDD acceptance states are automated.
