# Measured Oscillator Source Optimization

Date: 2026-09-15

## Context

Cycle V2 recipe measurements localized most work to mesh sources, but each
source bucket still combined several different operations.

## Decisions

- Split source timing into morph resolution, rasterization, sampling, gain,
  and stereo copying before selecting an optimization.
- Preserve the mature shared Cycle 1 rasterization and guide DSP as the
  authority. Prepare immutable products without caching per-frame noise,
  smoothing, or lifecycle state.
- Pair timing with operation counters, repeated Release 0/1/4/8-voice
  captures, exact output comparison, and realtime allocation/locking tests.
- Record findings and complexity contracts in the active TDD before changing
  algorithms; continue through implementation, review, verification, and commit.

## Generalized Rules

- A broad hot bucket is evidence for further attribution, not proof that its
  most visible function dominates.
- Prefer removing measured unused or invariant work while retaining the
  existing semantic implementation and floating-point operation order.
