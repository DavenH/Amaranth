# Workspace Visual Hierarchy

Date: 2026-09-18

## Context

The Cycle V2 canvas review exposed tension between visual simplification and
the product's goal of making signal structure visible instead of hiding it
behind tabs.

## Decisions

- Preserve the existing morph-axis, signal-domain, and envelope-section colour
  systems; they carry product meaning and must be changed cautiously.
- Keep the performance keyboard vertically compact. Prefer moving transport
  into marginal horizontal space over making the keyboard taller.
- Keep Curve Guide previews image-first and minimal; names are not required.
- Make persistent utilities narrower, lower-emphasis, and independently
  closable where practical rather than dividing the graph into hidden tabs.
- Use a compact unboxed signal legend and a neutral selection treatment.
- Make the expanded Trimesh editor wider, shorter, centred, and free of spy
  overlap.

## Generalized Rules

- Prefer visible graph structure over tab-based subsystem separation.
- Remove redundant semantic decoration when the preview already communicates
  signal type.
- Spend scarce vertical space on the graph and editors; move compact actions to
  marginal horizontal space.
- Mock up major source-to-sink graph-flow changes before changing stored graph
  positions.
- A nearly imperceptible paper-like canvas texture is desirable.
- Keep the minimap greyscale and visually quieter than graph content.
- Future graph groups should be collapsible without breaking visible flow: a
  collapsed Voice Context group should visibly feed the following voice-signal
  group, which should visibly feed Global FX.

## Open Questions

- Return signal probes to the graph as tethered nodes or retain a secondary
  dock.
- Rename `Spies` to `Wiretaps`.
- Hide the Trimesh Voice Context port until multiple contexts exist.
