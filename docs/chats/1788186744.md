# Session Summary

Date: 2026-08-31

## Context

The user reviewed several Cycle V2 expanded editors and identified a mixture of
functional regressions, visual/DSP mismatches, and inconsistent control-group
presentation.

## Decisions

- Prioritize broken interaction, truthful live visualization, and viewport
  containment before broad layout polish.
- IR visualization must share the audio preparation contract: High Pass updates
  live, Post gain is visible, and the zero-cutoff sampled trace demonstrates an
  identity relationship with the authored curve.
- Named control groups use a top-centered label with subtle spanning rules to
  both edges of the group.
- Expanded effect enablement should move into consistent upper-right chrome and
  use a semantic SVG toggle instead of an `Enabled` text row.
- Numeric entry preserves display alignment, edits only the number, and keeps
  units outside the editable field.

## Generalized Rules

- Separate synchronous feedback required by the active gesture from unrelated
  expensive recomputation; coalesce the latter.
- Treat nonfunctional toggles and escaping OpenGL content as correctness bugs,
  not aesthetic refinements.
- Reallocate a complete controls region before locally stretching or shrinking
  individual controls; preserve large hit targets independently of visible
  geometry.
- Use action-oriented product language in help text and avoid internal graph or
  model terminology.

## Open Questions

- Confirm the authoritative MIDI-note endpoint mapping used by key-scale morph
  dimensions.
- Confirm whether the requested 30-percent legend increase refers to the canvas
  utility legend.
