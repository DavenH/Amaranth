# Expanded Spy ADSR annotations and isolated automation

Date: 2026-10-25

## Context

The complete voice/release timeline needs compact visual phase annotations.
During verification, the workspace's persistent automation session was also the
instance the user was working in.

## Decisions

- Use small envelope diagrams above expanded Spies. Shade attack/decay/sustain
  for normal playback and the descending tail for release.
- Keep a full envelope outline visible in both icons; ASCII is insufficient.
- Run fixtures with coordinator `--clean` while the user uses the app. Verify the
  new PID and run-specific socket; workspace ownership alone does not establish
  that an instance is safe to reuse interactively.

## Generalized Rules

Prefer region shading within an envelope silhouette to text approximations for
ADSR phases. Distinguish process identity from user activity: an agent-launched
persistent app may later become the user's active session.
