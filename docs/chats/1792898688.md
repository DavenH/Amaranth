# Complete release tails in Spy previews

Date: 2026-10-25

## Context

The initial playback-cursor implementation reserved a fixed final fifth of Spy
width for release. The user clarified the intended time domain.

## Decisions

- Fit the whole voice duration plus the longest envelope release tail.
- Derive the release proportion per preset; do not reserve a fixed percentage
  or truncate release to a fixed quarter of the voice duration.
- Keep every Spy on that common time axis, with the unscratched waveshape held
  at x=1 and Guide noise still advancing during release.

## Generalized Rules

Prefer a duration-derived view that guarantees complete content over a fixed
visual ratio when the user asks to inspect envelope releases. Measure the
prepared envelope policy, including morph/controller inputs, rather than
inferring tail duration from a hard-coded display margin.
