# Cycle Preset Migration Review Batches

Date: 2026-09-13

## Context

Cycle 1 received a replacement factory-preset library. Cycle 2's existing
ports were archived before beginning a new migration, and layout quality needs
review before converting the complete library.

## Decisions

- Keep superseded Cycle 2 factory presets under `content/presets/old/`.
- Migrate a small, structurally representative batch before a full preset sweep.
- Name new Cycle 2 preset files in lowercase kebab case.
- Lay out signal flow from left to right, with parallel spectral branches stacked
  consistently and independent global processing on a separate row.
- Stack Voice Context configuration sources in port order in a compact column to
  its left, centre Voice Context against the stack, and continue audio flow to
  the right.
- Never synthesize a scratch Envelope from unrelated default geometry. Preserve
  authored scratch channels, and leave scratch unconnected when none is present.

## Generalized Rules

- Treat preset graph layout as reviewed product content, not incidental converter
  output.
- Reject cable tangles, unexplained overlap, and stacks that obscure graph flow
  even when the graph compiles.
- Use a representative review batch containing simple, branched, and effects-heavy
  graphs before approving bulk generation.

## Open Questions

- Confirm the review-batch layout before migrating the remaining Cycle 1 presets.

## Update (2026-09-14)

- Normalize Cycle 1's obsolete pitch-envelope modulation output ID 401 to the
  current ID 450; this is representation compatibility, not missing Cycle 2
  modulation support.
- Prefer default left-to-right port orientation whenever crowding does not
  require a rotation. Stack two operands feeding one operation vertically,
  place the operation to their right, and center a shared scratch Envelope to
  their left.
- Keep a separate global-processing lane close enough to remain visible at a
  useful canvas zoom; do not derive its vertical position from the deepest
  spectral auxiliary.
- Emit converted presets through Cycle 2's authoritative serializer. Generated
  files should already use its defaults, model versions, numeric spelling, and
  compact JSON shape so an ordinary edit does not rewrite the whole document.
- Preserve arbitrary per-destination modulation with native Cycle 2 graph
  sources. Prefer one modal Voice Context Modulation Triple plus compact local
  override Triples; do not discard sparse routes or expand them into visually
  noisy rows of redundant nodes.
- During a bulk pass, preserve reviewed destinations and local edits, emit every
  losslessly representable source, and report target-capacity or normalized-model
  blockers explicitly instead of clamping or truncating authored state.
