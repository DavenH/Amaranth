# CPU surface-colour experimentation

Date: 2026-09-28

## Context

Repeated shader tuning diverged from the synthetic copper/ice target. Blur and
shadow made the result fuzzier than straight mapping. The concrete reference
source is Stengah B0 Spy #1, not a substitute synthetic field.

## Decisions

Provide a small CPU Python experiment tool with editable gradients and independently
mapped low/high/band-pass layers. Let the user discover a recipe before porting it
into the production renderer. Keep a visible raw-colour baseline and explicit effects.

## Generalized rules

- Separate aesthetic experimentation from repeated C++ build/deploy cycles.
- Preserve source data and make display scaling, filtering and blending inspectable.
- Do not describe visual progress as closing a gap without convincing comparison.
- Saved recipes should make successful experiments reproducible and portable to a
  later implementation; the experiment tool itself need not claim shader parity.
