# Cycle 2 library tags and real keyboard input

Date: 2026-10-04

## Context

Preset and pattern rows had matching card chrome but different preview areas and
single-choice type filters. Empty search fields still failed to pass a native
macOS Space event to preview playback despite component-level key tests.

## Decisions

- Give the MIDI minimap the full card area behind readable title and tag chips,
  matching the preset spectrogram row.
- Curate saved preset tags by sound family and character. Use the same toggled
  chip-cloud interaction for preset and pattern filtering.
- Classify sax-named Cycle 2 presets as Brass, and Kicker and Stomper as Bass.
  Let people edit saved preset tags in the expanded browser.
- Verify keyboard shortcuts through the platform's real text-input path, not
  only by calling `keyPressed` directly in a component test.

## Generalized rules

Use shared UI components for matching controls, and inspect them at production
sidebar width. For text fields that reserve a key as a shortcut, test both
native text insertion and component key dispatch, then exercise an OS key event
in a running app when a user reports that the shortcut still fails.
