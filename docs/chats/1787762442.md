# Date

2026-08-26

# Context

Application UI reviews repeatedly accepted technically functional layouts with
distorted familiar proportions, wasteful empty regions, inconsistent control
scale, and controls whose visible size did not provide usable adjustment
precision.

# Decisions

- Treat visual footprint, hit target, manipulation mapping, and value indication
  as independent design contracts.
- Allocate layout space according to information value, usable manipulation,
  and recognizable reference proportions rather than equal distribution or
  container fill.
- Require production-size visual comparison and complete interaction evidence
  for nontrivial UI changes.
- For native-platform matching, judge a corpus of appearances, states, sizes,
  accessibility settings, and interactions rather than one static screenshot.

# Generalized Rules

- Derive familiar UI objects from shared reference geometry and document any
  deliberate deviation from their diagnostic proportions.
- Audit every large gap and region for a semantic purpose; avoid nested padding
  and stranded central space.
- Give precision-sensitive controls enough effective drag travel and an exact
  value indicator even when their visible footprint remains compact.
- Use current native controls and platform guidance as the authority when the
  stated quality bar is indistinguishability from system UI.
