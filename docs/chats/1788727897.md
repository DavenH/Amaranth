# Session Summary

Date: 2026-09-06

## Context

The user reviewed Cycle V2 control-group hierarchy and refined the visual rules
for dense expanded editors, especially Envelope.

## Decisions

- Remove wasteful outer group boxes, but use centered group names with quiet
  spanning rules to make scope explicit.
- Give peer button groups one deliberate toolbar region instead of positioning
  disconnected icon islands among sliders and parameter rails.
- Put Envelope purpose in the same action row as Markers, Scaling, and Zoom;
  increase the editor height when the control band needs more room rather than
  shrinking the graph.
- Replace low-resolution Cycle v1 atlas icons with purpose-built SVGs that
  preserve the original operation. Prefer lighter strokes and square line caps.
- Use slightly larger group-label typography; labels such as `Markers`,
  `Scaling`, and `Zoom` are preferable when the editor supplies the context.

## Generalized Rules

- Align peer group headings and controls to a small number of shared baselines.
- A compact icon must faithfully depict the operation, not merely resemble the
  legacy silhouette. Arrowheads should terminate precisely on the geometry
  they reference.
- Visually separate an action toolbar from continuous parameter controls when
  the actions otherwise appear arbitrarily scattered.
- Preserve information-bearing canvas space by increasing the containing
  editor when a clearer control layout genuinely needs more room.
