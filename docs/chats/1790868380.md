# Shared Cycle 2 MIDI pattern library

Date: 2026-10-01

## Context

The first Cycle 2 preview implementation embedded a distinct MIDI phrase in
every preset. The user preferred a reusable, named library.

## Decisions

- Supersede the inline-storage preference recorded in `1790824508.md` for new
  presets: store a stable pattern ID in each preset, with MIDI notes and
  automation in the shared pattern library. Keep legacy inline phrases readable.
- Curate a compact set of genuinely distinct patterns across sound types.
  Include basslines, lead melodies, slow pads, jazz keys and sax, sustained
  instruments, and percussion. Avoid near duplicates.
- Use mod wheel as the common automation lane. A pattern may contain CCs that
  a particular preset ignores; add other CC lanes where musically useful.
- Show pattern note minimaps in a dedicated Patterns sidebar tab and reuse the
  piano-roll editor for pattern creation and editing.

## Generalized rules

Prefer reusable musical demonstrations with clear rhythmic and harmonic
differences over one generated variation per preset. A shared pattern need
not be specialized to every modulation route it may be assigned to.
