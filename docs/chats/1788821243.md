# Session Summary

Date: 2026-09-07

## Context

Batch-converted Cycle V1 presets preserved their graph semantics, but their
generated node coordinates were treated as incidental and produced sprawling,
overlapping graphs when opened in Cycle V2.

## Decisions

- A migrated preset is not complete unless its initial graph presentation is
  tidy, compact, non-overlapping, and easy to scan.
- Prefer a streamlined left-to-right signal flow with aligned nodes and lanes.
- Use persisted port-side rotations deliberately for short switchbacks when
  they materially reduce graph width or cable crossings.
- Codify layout calculations in the converter so regenerated preset libraries
  receive the same quality rather than hand-arranging individual graphs.

## Generalized Rules

- Treat generated graph layout as durable preset content, not disposable UI
  metadata.
- Base spacing on production node footprints and shared gap constants; verify
  non-overlap and bounded occupied dimensions mechanically.
- Keep the main audio spine visually dominant. Place configuration attachments
  and modulation/envelope controls in aligned auxiliary lanes.
- Validate representative simple, effect-heavy, and maximum-node graphs at the
  production canvas size after regeneration.

## Open Questions

- Whether the converter-specific layout rules should eventually become a
  reusable graph auto-layout service for user-authored graphs.
