# Reproduce trackpad UI gestures with their full event sequence

Date: 2026-10-07

## Context

Scripted right clicks retained a Trimesh vertex's X coordinate while physical
two-finger trackpad clicks sometimes moved it to zero. The user supplied a
full-window video and repeated the gesture in an isolated debug session.

## Decisions and rules

- Treat a user-reproduced physical interaction as open even when synthetic
  pointer commands pass. Compare actual event logs and model state before
  changing mesh behavior.
- Record UI automation as window video when timing or flicker matters. Include
  the mouse-down, any wheel or drag event, and the settled model result.
- Keep isolated native-input sessions separate from other Cycle instances and
  fixture runs so clicks and cleanup target the intended app.
