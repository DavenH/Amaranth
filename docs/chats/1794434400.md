# Keep processing distinct from neutral graph endpoints

Date: 2026-11-11

## Context

Moving gain processing to a hidden pre-wet tap left its control attached to the
final Output node, obscuring the actual signal chain.

## Decisions

Gain is a visible processing node wired before wet effects. Global Out matches
Global In as a neutral, non-deletable endpoint.

## Generalized Rules

Represent processing where it occurs in the graph. Keep global endpoints neutral
and preserve authored identities and settings through explicit format migrations.
