# Unblended harmonic lanes in Spies

Date: 2026-10-25

## Context

The expanded Spy spectrum used a continuous interpolated heatmap while Trimesh
magnitude views already showed stepped harmonic bands.

## Decisions

- Present Spy magnitude spectra with distinct unblended harmonic lanes, matching
  the existing Trimesh presentation.
- Retain the ADSR region annotations above the expanded Spy.

## Generalized Rules

Reuse the existing harmonic band renderer and logarithmic lane placement.
Prevent subsequent image scaling from blending the rows back together. Keep
value contrast separate from frequency placement, and exclude FFT DC when
adapting data whose first row differs from authored Trimesh harmonics.
