# Trimesh navigation and release-only publication

Date: 2026-10-23

## Context

The user ended the saxophone modelling experiment after rejecting its sound and
requested a fresh branch from main to fix Trimesh interaction regressions.

## Decisions

- Stop the saxophone experiment; do not resume it without a new request.
- Treat primary-axis morph movement as local slice navigation. It must not
  increase graph edit/document/model versions or create undo history, including
  on mouse-up.
- Keep cube movement local until mouse-up. A held pointer must not publish graph
  updates or rebuild the whole graph; release commits the final coordinates in
  one undoable transaction.
- Integration coverage must exercise actual slider/cube pointer routing and
  revision/work counters. Semantic command-only tests can miss broken visual
  feedback or expensive transient graph updates.

## Generalized Rules

Separate ephemeral inspection/navigation from durable authoring. Preserve both
visible control response and per-gesture publication cost through merges.
