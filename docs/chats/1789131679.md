# Session Summary

Date: 2026-09-11

## Context

A Cycle 2 Trimesh gesture performed whole-mesh Guide preparation and replacement
inside a local vertex drag, changing an O(1)-scope mature interaction into O(n)
work and invalidating retained pointers.

## Decisions

- Treat asymptotic parity with mature Cycle 1 interactions as correctness.
- Audit pointer-down, each movement update, and commit separately.
- Do not accept throttling, background work, caching, or small presets as a
  remedy for work whose input scope is wrong.
- Enforce the contract with deterministic operation counts and scaled unrelated
  graph/model content.
- Permit one narrowly scoped undo-state capture at a gesture boundary during
  migration, but make invertible semantic deltas the final undo/redo model.

## Generalized Rules

- A semantic delta may scale only with changed objects and required local render
  output, never unrelated graph, resource, audio-sample, or model size.
- Live updates must not clone graphs/models, serialize for change detection, or
  prepare durable resources.
- Undo applies the inverse semantic delta and redo reapplies the forward delta;
  neither should require a document-sized snapshot.
- Preserve Cycle 1 complexity along with visible behavior whenever mature
  interaction is reused in Cycle 2.
