# Preview Morph Ownership and Envelope Presentation

Date: 2026-09-17

## Context

Cycle V2 editor morph cursors needed to follow the MIDI preview note and mod
wheel. The ownership of those values was ambiguous, and hiding Envelope
storage-only depth points accidentally hid the colored depth lines as well.

## Decisions

- Preview note and mod wheel overwrite saved Trimesh/Envelope morph values;
  they are not only a temporary displayed slice.
- Keep mod-wheel Spy refresh on release by default; a drag must not perform
  synchronous Spy work or graph edits on every movement.
- Hide misleading Envelope depth point markers without hiding their
  color-coded connecting lines.

## Generalized Rules

- Resolve presentation-versus-durable ownership explicitly before wiring
  preview controls to editor state.
- When suppressing one visual layer, test adjacent layers that share its
  renderer pass, and verify through an actual-size capture and a gesture test.
