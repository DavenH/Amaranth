# Mesh dimensionality and default morph mapping

Date: 2026-10-20

## Context

Reducing morph dimensions should simplify authoring and remove evaluation work.
Envelope's hidden Yellow poles suggested unifying it with Trimesh.

## Decisions

- Both node families support Static, Yellow-only, Red/Blue, and all three axes.
  Call the morph axis Yellow so envelope playback time remains unambiguous.
- Reduction bakes dismissed coordinates and extrudes orthogonal rails. Preserve
  retained-axis variation, discard dismissed variation, and recover it through
  undo. Hidden retained variation and its collision constraints are frustrating.
- New nodes start Static. 1D retains its useful surface and one morph rail;
  Static has neither morph chrome nor a surface. Reclaim unused editor space.
- Envelope gains Yellow but latches all morph inputs at note-on. Share geometry
  and input mechanics while keeping envelope and oscillator playback owners.
- Keep shared axis colours. Modulation Triple has Trimesh and Envelope mapping
  columns. Defaults differ only on Yellow: Voice Time versus Unmapped.
  Unmapped uses the destination's authored coordinate; cables override defaults.
- Legacy Envelopes project Yellow=0 onto full orthogonal Yellow poles. Old
  presets keep their prior dimensionality and Red/Blue mapping behavior.

## Generalized rules

Distinguish geometric axes from their modulation sources. Simplified modes must
remove invisible editing constraints, not merely hide controls. Prefer shared
mechanics with domain-owned temporal policies over merging different lifecycles.
