# Mesh dimensionality and default morph mapping

Date: 2026-10-20

## Context

Reducing morph dimensions should simplify authoring and remove evaluation work.
Envelope's hidden Yellow poles suggested unifying it with Trimesh.

## Decisions

- Trimesh descends YRB -> YR -> Y -> Static; Envelope keeps its Red/Blue 2D
  plane for compatibility. Keep an active primary view axis unchanged.
  Call the morph axis Yellow so envelope playback time remains unambiguous.
- Reduction bakes dismissed coordinates and extrudes orthogonal rails. Preserve
  retained-axis variation, discard dismissed variation, and recover it through
  undo. Hidden retained variation and its collision constraints are frustrating.
- New nodes start Static. 1D retains its useful surface and one morph rail;
  Static has neither morph chrome nor a surface. Keep surviving rails, gain,
  and vertex parameter rows in stable positions across modes.
- Envelope gains Yellow but latches all morph inputs at note-on. Share geometry
  and input mechanics while keeping envelope and oscillator playback owners.
- Keep shared axis colours. Modulation Triple has Trimesh and Envelope mapping
  columns. Defaults differ only on Yellow: Voice Time versus Unmapped.
  Unmapped uses the destination's authored coordinate; cables override defaults.
- Legacy Envelopes project Yellow=0 onto full orthogonal Yellow poles. Old
  presets keep their prior dimensionality and Red/Blue mapping behavior.

- Label dimension controls “Curve morphing”; coloured ticks identify the active
  axes. A hover bubble on destructive options is enough warning; no modal dialog.
- Keep the cube in 3D and give 2D its matching plane with colour blending,
  authored geometry, highlights, axis rails and projected cursor.
- Compact Trimesh curve previews use the same panel/snapshot mechanism as
  effect editors, including their curve, fill, grid and point language.

- Keep inapplicable vertex properties visible and disabled so the stack remains
  continuous. Component curve is a separate selector in every mode.
- Show the 2D plane head-on as a square, with crisp offset, extended axis bars.
  1D keeps a line diagram showing linked/selected endpoints.
- Prefer a smaller Static editor to filling the former surface area with more
  content. Preserve control anchors when reducing the surrounding layout.
- Slider travel is inviolable: compact layout must preserve usable adjustment
  range before allocating surface space. Keep tracks moderately sized; a larger
  hit target cannot make a shortened track usable.
- Put Component curve below the coordinate/property sliders (supersedes the
  earlier first-row placement). Explain its segment-level meaning with two
  intercepts and a wave-shaped curve between them. Keep output gain with the
  inspector rather than floating below the Static curve.

## Generalized rules

Distinguish geometric axes from their modulation sources. Simplified modes must
remove invisible editing constraints, not merely hide controls. Prefer shared
mechanics with domain-owned temporal policies over merging different lifecycles.
