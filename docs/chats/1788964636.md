# Session Summary

Date: 2026-09-09

## Context

Adding a default scratch-envelope input to Voice Context required both a
production-context UI review and proof that inherited scratch behaves exactly
like equivalent direct Trimesh attachments.

## Decisions

- Keep every Voice Context input on the left; port placement is not a concern
  for this node family.
- Review UI work automatically in the connected production graph, not only as
  isolated geometry or unit tests.
- Before presenting UI work, anticipate feedback about containment, spacing,
  semantic identification, cable readability, fit-zoom legibility, and complete
  replace/remove/undo interactions.
- Treat a visible output change between semantically equivalent graph forms as
  a real defect, including changes caused by retained preview state.

## Generalized Rules

- A UI feature is not ready for user review until it has received a deliberate
  production-size UX pass and focused interaction automation.
- Preserve established port-side conventions unless the user can author the
  same placement through the existing port rotator.
- Semantic equivalence must include live preview behavior across graph edits,
  not just fresh offline executions.
