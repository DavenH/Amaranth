# Voice Context compact cues

Date: 2026-10-12

## Context

The collapsed Voice Context replaced prose with compact port and property cues.
The octave arrow and number were too small and ambiguous at normal canvas zoom.

## Decisions

- Use conventional octave notation (8va/8vb; 15ma/15mb for two octaves) in
  Voice Context iconography, at a size comparable to the duration cue.
- Always show the octave state. `Oct 0` read like a date, so use a muted,
  struck-through ottava symbol for an unshifted voice.
- A visible `+` beside an empty input should create its compatible source on
  one click. Keep cable dragging on the socket.
- When adding a source between connected inputs, open space in the existing
  source stack and preserve its cable order.
- New pitch and scratch envelopes should begin with Cycle 1's flat and linear
  defaults respectively.

## Generalized Rules

Prefer familiar musical notation over tiny generic arrows for musical values.
Place authoring shortcuts where the pointer affordance is drawn, while keeping
the port's primary cable gesture available.
