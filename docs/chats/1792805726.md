# Wave reference discovery and neutral UI accents

Date: 2026-10-23

## Context

Cycle V2 references were discoverable mainly through File import and could
appear later when a Trimesh editor opened. The user requested a deliberate
tray workflow and proposed shared-sidebar asset browsing.

## Decisions

- Make the reference tray expandable on demand, independent of node editors.
- Provide an Assets sidebar with the existing search/control language, short
  audio waveforms (up to four seconds), audition and drag-to-tray.
- Keep wave card information useful; duration sublabels do not earn space there.
- The user explicitly requested no cyan. Use neutral accents for the new
  workflow, including waveform previews, selection, disclosure and scrollbars.

- The user rejected boxed text actions as "dev ui" and requested appropriate
  sidebar tab icons. Prefer semantic icon actions with tooltips and a cohesive
  vector family; keep section names as headings.
- Sum stereo channels into one waveform and normalize its display so quiet
  source gain does not contradict normalized audition loudness. Drag ghosts
  should show only the selected item, never the whole list.

## Generalized Rules

Prefer an explicit, discoverable authoring action over delayed UI expansion
caused by unrelated editor state. Check inherited framework colors as well as
newly painted accents when honoring color preferences.
