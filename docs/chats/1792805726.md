# Wave reference discovery and neutral UI accents

Date: 2026-10-23

## Context

Cycle V2 references were discoverable mainly through File import and could
appear later when a Trimesh editor opened. The user requested a deliberate
tray workflow and proposed shared-sidebar asset browsing.

## Decisions

- Make the reference tray expandable on demand, independent of node editors.
- Provide an Assets sidebar with the existing search/control language,
  previews of the first five seconds, audition and drag-to-tray.
- Keep wave card information useful; duration sublabels do not earn space there.
- The user explicitly requested no cyan. Use neutral accents for the new
  workflow, including waveform previews, selection, disclosure and scrollbars.

- The user rejected boxed text actions as "dev ui" and requested appropriate
  sidebar tab icons. Prefer semantic icon actions with tooltips and a cohesive
  vector family; keep section names as headings.
- The user subsequently restored the existing preset/pattern New/Edit/Rename/
  Delete text row. Keep that specific row as text buttons; the sidebar tabs and
  reference asset/tray actions retain their icons.
- Sum stereo channels into one waveform and normalize its display so quiet
  source gain does not contradict normalized audition loudness. Drag ghosts
  should show only the selected item, never the whole list.
- Reference cards retain insertion order when selected. Double-click expands
  the reference with its pitch envelope below its cyclogram; keep the tray
  visible rather than replacing it with a detached envelope strip.

- Expanded reference navigation shares the recording's normalized time range
  between the cyclogram/spectrogram and pitch curve. Remove the pitch editor's
  release region; it is an audio reference rather than a note-release editor.
  Keep the ordinary envelope panels' release behavior.
- Provide inlaid icon actions for attack, pitch-range fit and full view. Compare
  framing before attributing apparent sharpness differences to analysis size.

- Reference spectra follow Cycle 1's tracked-cycle resampling and power-of-two
  transforms. Display harmonic 1 in the first slot, omit DC and use the standard
  magnitude log mapping; do not transform a low-resolution display thumbnail.
- Expanded references use cycle-based resolution: load the first five seconds,
  show each cycle up to 1024 evenly selected cycles, and cap presented phase/
  frequency rows at 1024. Preserve real cycle times for linked pitch navigation.
- Cyclogram/spectrogram mode belongs to each reference and stays consistent in
  its tray card and expanded editor. Offer a compact icon pill on each card.
- Vertical space belongs to the plots. Replace the reference pitch heading row
  with the existing pitch icon inside the envelope's top-left corner; inlay its
  controls rather than reserving a separate text band.
- Keep the reference's linked time scrollbar only below the pitch envelope;
  remove duplicate surface zoom bars and the fundamental slider/readout.
- Asset previews show the first five seconds even for longer recordings. The
  user accepted the waveform density experiment: time/amplitude positions with
  brighter pixels for repeated trace passages. Keep previews cached and prefetch
  adjacent pages for scrolling.
- The expanded reference's lower panel switches between pitch and waveform
  density using inlaid icons. All plots share time zoom; preserve independent
  vertical pitch/amplitude ranges. Show a line trace when the visible window
  contains at most one zero crossing per rendered horizontal pixel.

## Generalized Rules

Prefer an explicit, discoverable authoring action over delayed UI expansion
caused by unrelated editor state. Check inherited framework colors as well as
newly painted accents when honoring color preferences.
