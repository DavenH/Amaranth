# Session Summary

Date: 2026-10-08

## Context

Cycle 2 graph grids, expanded Trimesh editing, and preset loading were measured
against Cycle 1 behavior. Fast graph execution still felt slow when redundant
diagnostics, realtime preparation, or cold JUCE painting ran on the UI path.

## Decisions

- Measure the visible result: completion of the first full canvas paint for a
  preset load, and the expanded Spy grid for a grid comparison. Report Debug
  and Release separately, with the same presets, machine, power state, and
  repeated warm-app runs. Keep individual load values as well as means.
- Request the graph product actually needed. An expanded Spy needs its selected
  upstream path and high-density output, without unused compact grids or
  downstream wet effects. A Spy placed after a wet effect still includes it.
- Realtime audio preparation must not prewarm discarded Trimesh traversal
  grids. Diagnostic grid capture preserves exact output without that warmup.
- During an expanded editor gesture, update its local surface without
  repainting the whole canvas or refreshing compact previews for each move.
  Publish the broader refresh at the gesture boundary.

## Generalized Rules

- Separate graph preparation, preview audio, grid execution, cold node tiles,
  Spy tiles, message scheduling, and OS presentation in reports. Do not call a
  posted message turn an idle queue or treat preview audio as Spy-only work.
- Protect scope with semantic and operation-count tests. Timing alone is too
  sensitive to build configuration, cache state, and power state.
- Optimize expensive cold node tiles, including Reverb, at the established
  renderer/cache boundary. Preserve visible material behavior; measure the
  displayed tile size before changing raster resolution.
- Keep the expanded grid's native high density and curve/noise behavior unless
  measured visual and semantic parity justifies a resolution change.
- Use the performance regression loop in `docs/cycle-agent-runbook.md` and the
  measured contracts in `docs/TDD/cycle-v2-preset-load-latency.md` before
  changing graph preparation, preview, or canvas invalidation.

## Open Questions

  material and shared cache behavior?
