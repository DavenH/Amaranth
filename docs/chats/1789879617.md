# Inline Preset Access

Date: 2026-09-20

## Context

The full preset browser established a visual language worth carrying into the
main workspace without replacing the deeper editor.

## Decisions

- Put a compact preset browser in the right sidebar beside Curve Guides, using
  two tabs named Curves and Presets; do not add the mockup's Browser tab.
- Reuse the full browser's previews, async search, styling, and interaction
  semantics in a compact selected-preview plus vertical-list treatment.
- Keep `Browse Files...` as the route to the full preset-browser editor.
- It is acceptable for the inline Presets view to hide the minimap for now, but
  retain the minimap implementation for future relocation.
- Use larger search-field typography than the first full-browser iteration.

## Generalized Rules

- Reuse established visual and data-loading systems when adding compact views;
  adapt geometry, not semantics.
- Prefer one obvious compact access point plus a route to the full editor.
- Temporary visual occlusion is acceptable when future layout is undecided;
  preserve the displaced feature's implementation.
