# Persistent Spy release auditions and native geometry

Date: 2026-10-25

## Decisions

- Save each Spy's committed release position with the preset. Compact and expanded
  views must show the same audition and retain it across closing/reopening.
- This supersedes the ephemeral-setting decision in 1792944571.md. Movement still
  gives cheap cursor feedback; only pointer-up renders and changes metadata.
- Use moderate exponential curves for the ADSR annotation icons.

## Generalized Rules

An apparently unresponsive control may have an offset hitbox. Compare native
screen targets with actual painted geometry before changing the hitbox policy.
Use one rectangle for painting, interaction and automation. Verify partial
repaints preserve overlay dimming; invisible hover text can still trigger status
activity. Keep UI verification in an isolated exact-PID instance.
