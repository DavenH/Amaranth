# Cycle 2 pattern curation and browser

Date: 2026-10-01

## Context

The first shared pattern library shipped 29 composed phrases. The user reviewed
the actual Patterns sidebar and found the set too large and the compositions
unconvincing for factory content.

## Decisions

- Supersede the breadth target in `1790868380.md`: ship about five simple,
  clearly typed audition templates for now. A basic bassline must be included.
- Tag patterns by sound type so the browser can narrow the list.
- Keep selection from changing the list's scroll position.
- Favor compact, polished controls and use a subdued automation color instead
  of bright cyan.

## Generalized rules

Treat factory MIDI patterns as useful starting points, not finished musical
compositions. Review density and interaction at the sidebar's actual size.
