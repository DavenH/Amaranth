# Cycle 2 library browser consistency

Date: 2026-10-04

## Context

The Presets and Patterns sidebar tabs exposed similar search and list tasks
with visibly different fields, icons, spacing, and row layouts.

## Decisions

- Use one search component for library browsers, including the same icon,
  height, inset, and empty-field Space playback behavior.
- Align the Presets and Patterns toolbar and row geometry at actual sidebar
  size. Keep controls compact and avoid redundant list counts or hero cards.
- Keep sibling library actions in one shared toolbar component. A change to
  New, Edit, Rename, Delete, or search layout must appear in both sidebar tabs;
  validate their bounds together before considering either tab finished.
- A pattern name is entered through New; the persistent field searches.
- Make preset spectrograms fill the row behind readable title and type chips.

## Generalized rules

When sibling browsers offer the same interaction, use shared presentation code
and check the result in production-size screenshots. Keep row selection stable
and avoid scrolling the selected item to the top automatically.
