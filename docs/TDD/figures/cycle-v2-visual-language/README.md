# Cycle V2 Visual Language References

These images are supporting evidence for:

- [`cycle-v2-visual-language-convergence.md`](../../cycle-v2-visual-language-convergence.md)
- [`cycle-v2-scalar-surface-shader.md`](../../cycle-v2-scalar-surface-shader.md)

`current-workspace.png` is the production Cycle V2 baseline supplied during the
design review. The small browser, spy, Trimesh, keyboard, Envelope, and status
images are crops from the accepted visual-language exploration. The surface and
3D-editor images are generated directional mockups.

The mockups are not pixel specifications. Their TDD captions identify the
semantic treatment, hierarchy, or interaction idea to preserve and the
exaggerated scale, glow, or ornamentation to discard during production review.
